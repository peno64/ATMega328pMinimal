Bare minimum - Arduino on breadboard




The Arduino uses the ATMega328p chip. We can get that in a SMD format (ATMega328p-AU) or the DIP format for trough hole soldering (ATMega328p-PU). But, the chip by itself can't work. It needs a few more components and all together is called the bare minimum configuration of this chip.







PART 1 - The simple schematic

Below we have the schematic for this configuration. As you can see we need a supply of 5 volts. This supply has to be very well regulated with no voltage spikes. For that add an extra 10uF capacitor between 5V and GND. Also, the reset pin is negative enabeled. So, in order to have it disabeled, we need to apply 5V to it. For that, a 10k ohms resistor is placed between RESET and 5V.
Note that there is 5V on pin 7 and on pin 20. Both must be connected to 5V. They are not internally connected in the ATmega328P. One is the digital 5V and the other the analog 5V. The same for GND on pins 8 and 22.




Also, the ATMega328, usually works at 16MHz. For that, between pins 9 and 10 we place a 16MHz (18 pF) crystal. But this crystal, in order to oscillate needs two capacitors of exactly 22pF connected to GND. In the figure above, you have all the pins of the chip. Right now, if the microcontroller has a bootloader, we could upload a code. But let's imagine it doesn't have a bootloader.






PART 2 - Burn bootloader

Now, let's imagine the chip doesn't have the bootloader (virgin chip).

To upload a bootloader, another Arduino is needed and this Arduino needs a special sketch: an ISP programmer.
This Arduino can for example be an Arduino UNO but also an Arduino NANO works.
Note that this Arduino doesn't have to be wired yet to the ATmega328P. Just connect the Arduino via USB to your computer at this time.
Open Arduino IDE and go to File, Examples, Arduino ISP and open that example.
Select the COM port of the Arduino board and upload this code.





Then disconnect the Arduino from the computer and make next connections from the Arduino UNO/NANO to the ATmega328P if that isn't done yet. These are the SPI pins, CLOCK, MISO and MOSI.
Note that the Arduino powers the ATmega328P at this moment. There is no extra power source needed.

This can also be done with an Arduino NANO.
Then use the following connections:

Important: disable auto-reset on Nano
Put a 10µF capacitor between the RESET and GND pins of the Arduino Nano (not the ATmega328P). This prevents the Nano from resetting when the IDE tries to program it.
Positive leg -> RESET of Nano
Negative leg -> GND of Nano

Note again that the Arduino powers the ATmega328P at this moment. There is no extra power source needed.
Again plug the usb port of the Arduino to your computer.
Now it's time to burn the bootloader. Go to Tools → programmer → Arduino as ISP. By that we change the programmer to ISP.




Select the board as Arduino UNO
Note that the board that you select here determines which bootloader will be uploaded to the ATmega328P.
So also when an Arduino NANO is used as ISP, Arduino UNO must be selected here.
Finally, go to Tools → Burn bootloader. Now the LEDs of the Arduino will blink a lot.
Once you get the message of bootloader burned we are good to go.




Disconnect the Arduino from ATmega328P. It's no longer needed.



PART 3 - Upload a code

Now, we have the bootloader so we can communicate with the RX and TX pins and upload a code. For that we need and FTDI module. Make the next connections and uploade your code.
An FTDI module is a USB to TTL converter that uses a chip made by the company FTDI (Future Technology Devices International), typically the FT232RL chip.
Note that also a simpler USB to TTL converter can be used based on chips CH340, CP2102, PL2303 etc.
If your module has the DTR pin available then it can auto-reset during upload. Not all cheap USB to TTL modules break out the DTR pin. If the pin is not there then you have to do a manual reset of the ATMega328 when upload starts.


For a CH340, the Auto-Reset mod can be done by adding a thin piece of wire connected to the DTR (pin 13) on the CH340 chip.
The following image shows the DTR pin to which the wire has to be soldered:



Connect it via a 100nF capacitor to pin 1 (RESET) of the ATmega328P for automatic reset without needing the button.
So don't connect this DTR wire from the CH340 directly to RESET of the ATmega328P because then upload will work but the sketch will not run because RESET will be permanently set.
A 100 nF capacitor must be put between it. Note that any capacitor between 10 nF and 1µF should work.

Reset circuit (required for auto-reset during upload)

If your module has no DTR pin, you need to manually reset the ATmega328P at the right moment during upload: - Connect a momentary push button between pin 1 (RESET) and GND
- Add a 10k ohm resistor between pin 1 (RESET) and 5V (pull-up)



Upload procedure:

1. Click Upload in Arduino IDE
2. Wait until you see "Uploading..." in the status bar
3. Briefly press the reset button if DTR is not connected)
4. Upload should proceed
